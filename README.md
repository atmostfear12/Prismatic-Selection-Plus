# Prismatic Selection+

Prismatic Selection+ is a lightweight client-side Fabric mod for Minecraft 26.2 that replaces the vanilla block-selection outline with a customizable prismatic effect.

## Features

- Animated rainbow selection outline
- Solid-color mode
- Adjustable rainbow speed
- Adjustable saturation and brightness
- Adjustable line thickness
- Native in-game configuration screen
- Persistent settings
- Optional Mod Menu integration
- Client-side only

## Requirements

- Minecraft 26.2
- Fabric Loader 0.19.0 or newer
- Fabric API
- Java 21 or newer

Mod Menu is optional.

## Building

Clone the repository and run Gradle's `build` task with a compatible JDK. The development build currently targets Java 25 via the Gradle toolchain while the mod metadata allows Java 21+.
